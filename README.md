# Programming Basics

Homework solutions for the 1st year "Programming Basics" course at SPbU.

## What's here

- **ztasks/** -- C++ problem sets (topics 1-5: basics, loops, arrays, strings, sorting, etc.), each folder has the source and test files
- **qt_pancakes/** -- a small Python + Qt project (pancake sorting visualization)
- **old-pancake/** -- earlier console version of the pancake sorter in Python
